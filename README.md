# Utami Jaya – Online Printing & Order Management Platform

Utami Jaya is a Laravel-powered web platform designed to modernize traditional printing services by offering a seamless online ordering and management experience. Customers can register, browse products, place orders, and complete secure payments via Midtrans. The system includes a real-time chat support feature, an admin dashboard for order tracking, content editing, and PDF report generation—streamlining both customer and administrative workflows for print businesses.

## 🌐 Features
- 🖨️ Online printing service with dynamic product selection
- 💳 Midtrans-integrated secure payment system
- 👤 Customer registration and authentication
- 💬 Real-time in-app chat support (Chatify)
- 🧾 Admin dashboard for managing orders, reports, and website content
- 📄 Invoice generation in PDF format
- 📱 Responsive UI with TailwindCSS and BootstrapJS

## 🛠️ Tools & Technologies
**Framework & Language**: Laravel 9, PHP 8  
**Database**: MySQL  
**Frontend**: Blade, TailwindCSS, Bootstrap JS, jQuery, JavaScript, HTML  
**Backend Tools**: Laravel Sanctum, Midtrans PHP SDK, Munafio Chatify, GuzzleHTTP  
**Build Tools**: Composer, Vite  
**Version Control**: Git
